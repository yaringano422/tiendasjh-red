# Multi-Device Web Catalog (Hacia plataforma B2B)

Plataforma web diseñada para la visualización de productos en tiempo real, funcionando como puente hacia un modelo de negocio Business-to-Business.

## 🌟 Características Destacadas
* **Sincronización Multi-dispositivo:** Gracias a Supabase, los cambios se reflejan instantáneamente en todos los terminales.
* **Arquitectura Escalable:** Construido con TypeScript para un código robusto y mantenible.
* **Despliegue Continuo:** Alojado en Vercel con integración de Git.
* **UI/UX:** Diseño responsivo optimizado para navegación fluida.

## 💻 Stack Tecnológico
* **Frontend:** React, TypeScript.
* **Backend as a Service:** Supabase (PostgreSQL, Realtime).
* **Hosting:** Vercel.

## 🔧 Instalación
1. Clonar el repo: `git clone https://github.com/yaringano422/tiendasjh-red`
2. Instalar dependencias: `npm install`
3. Correr en local: `npm run dev`
